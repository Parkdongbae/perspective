# PRD: 손 핀치 조작 (카메라로 선 긋기·지우기)

작성일 2026-11-14 · 대상 앱: 투시도 놀이터

## 1. 배경과 목표

지금은 마우스·터치로만 선을 긋고 지운다. 전자칠판이나 노트북 앞에서 학생이 **카메라에 손을 비추고 허공에서 핀치(손가락 맞대기)** 로 선을 긋고 지울 수 있게 한다. 몸을 쓰는 조작으로 수업 참여도를 높이고, 화면을 직접 만지기 어려운 환경(큰 화면, 프로젝터)에서도 쓸 수 있게 하는 것이 목표다.

성공 기준
- 카메라를 켠 뒤 설명 없이도 1분 안에 선 하나를 긋고 지울 수 있다.
- 학습·따라하기·연습장 세 모드 모두에서 기존 마우스/터치와 같은 결과가 나온다.
- 손 조작을 꺼 두면 기존 동작과 성능에 아무 변화가 없다.

## 2. 사용자

- 초·중학생: 손 조작으로 선을 긋고 지운다.
- 교사: 카메라를 켜고 끄며, 문제가 생기면 마우스로 바로 이어서 진행한다.

## 3. 확정된 결정

| 항목 | 결정 |
|---|---|
| 적용 범위 | 학습 · 따라하기 · 연습장 모두 |
| 긋기/지우기 구분 | 엄지+검지 핀치 = 긋기(누르기), 엄지+중지 핀치 = 지우기 |
| 카메라 화면 | 화면 왼쪽 아래 구석의 작은 거울 영상 + 손 뼈대 |
| 손 인식 엔진 | MediaPipe Hand Landmarker, 카메라를 켤 때 CDN에서 내려받음 |

## 4. 기능 요구사항

### 4.1 켜고 끄기
- 모든 화면 왼쪽 아래에 `🖐 손으로 그리기` 버튼을 둔다. 누르면 카메라 권한을 요청하고 손 인식을 시작한다.
- 다시 누르면 카메라를 완전히 끈다(카메라 표시등이 꺼져야 한다).
- 켜짐 상태는 저장하지 않는다. 새로 열면 항상 꺼진 상태로 시작한다.
- 화면(홈 ↔ 단계 ↔ 플레이)을 옮겨도 켜진 상태가 유지된다.

### 4.2 손 커서
- 엄지 끝 위치를 화면 커서로 쓴다(긋기·지우기 두 핀치에 공통인 손가락이라 핀치 종류가 바뀌어도 커서가 튀지 않는다).
- 영상은 거울처럼 좌우를 뒤집어, 손을 오른쪽으로 움직이면 커서도 오른쪽으로 간다.
- 카메라 화면의 가운데 영역(가로 15–85%, 세로 12–80%)을 화면 전체에 대응시켜, 팔을 크게 뻗지 않아도 구석까지 닿게 한다.
- 손떨림은 속도에 따라 강도가 바뀌는 필터(One Euro)로 줄인다: 천천히 움직일 때는 안정적으로, 빠르게 움직일 때는 지연 없이.

### 4.3 핀치 제스처
- 핀치 판정: (엄지 끝–손가락 끝 거리) ÷ (손 크기). 0.25 아래로 2프레임 이어지면 누름, 0.40 위로 2프레임 이어지면 뗌. 누름·뗌 기준을 달리해 선이 중간에 끊기지 않게 한다.
- 검지와 중지가 모두 가까우면 더 가까운 쪽을 고르되 긋기를 우선한다. 한 번 정해진 종류는 뗄 때까지 바뀌지 않는다.
- 손이 0.3초 넘게 화면에서 사라지면 누름을 끝낸다(긋던 선은 거기까지 확정).

| 제스처 | 연습장 | 학습 · 따라하기 |
|---|---|---|
| 엄지+검지 핀치 후 이동 | 현재 도구로 동작(소점·투영선·직선·펜·지우개·화면 이동) | 점에서 소점/점으로 끌어 선 긋기, 남는 선 눌러 지우기 |
| 엄지+중지 핀치 | 현재 도구와 상관없이 지우개 | 남는 선 눌러 지우기(이 모드의 지우기는 원래 '누르기') |
| 버튼 위에서 검지 핀치 | 버튼 누르기(도구 선택, 힌트, 되돌리기, 뒤로 등) | 같음 |

### 4.4 화면 표시
- 커서: 평소 파란 고리, 긋는 중 파란 점, 지우는 중 빨간 점.
- 구석 미리보기: 거울 영상, 손 뼈대, 인식 영역 테두리, 현재 상태(`손을 보여 주세요` / `✏️ 긋는 중` / `🧽 지우는 중`), 제스처 안내 한 줄.
- 미리보기와 커서는 마우스 입력을 가로채지 않는다.

### 4.5 오류 처리
- 카메라 권한 거부, 카메라 없음, 다른 프로그램이 사용 중, 인터넷 문제로 엔진을 못 받은 경우를 각각 다른 문구로 알려 준다.
- 오류가 나면 꺼진 상태로 돌아가고, 마우스/터치는 그대로 쓸 수 있다.

## 5. 기술 설계

- 새 파일 `js/hand.js` 하나에 카메라, 손 인식, 제스처 판정, 커서·미리보기를 모두 담는다.
- 손 입력은 **합성 포인터 이벤트**(`pointerdown/move/up`)로 바꿔 커서 아래 캔버스에 보낸다. 학습·따라하기 엔진(`engine.js`)과 연습장(`sketch.js`)이 이미 포인터 이벤트로 동작하므로 게임 로직은 바꾸지 않는다.
- 지우기 핀치는 포인터 이벤트 표준의 지우개 버튼(`button = 5`)으로 보낸다. 연습장은 이 값을 보면 그 한 획만 지우개로 처리한다(펜 태블릿의 지우개 버튼도 덤으로 동작).
- 엔진과 모델은 손 조작을 처음 켤 때만 내려받는다. 켜지 않으면 추가 로딩이 없다.
- 카메라는 `https` 또는 `localhost`에서만 열린다. 배포 주소는 `https`여야 한다.

## 6. 하지 않는 것

- 양손 동시 조작, 두 손 확대/축소.
- 손으로 목록 화면 스크롤, 슬라이더(두께·확대) 조절 — 마우스/터치로 한다.
- 오프라인 동작(엔진·모델 내장).
- 영상 저장·전송: 영상은 브라우저 안에서만 처리하고 어디에도 보내지 않는다.

## 7. 확인 방법

- 합성 손 좌표를 넣어 세 모드에서 긋기·지우기·버튼 누르기가 되는지 자동 점검.
- 실제 카메라로: 밝은 교실/역광/카메라와 50cm·1.5m 거리에서 핀치 인식과 선 끊김 여부 확인. 기준값(0.25 / 0.40, 인식 영역)은 `js/hand.js` 맨 위 상수로 조절한다.
